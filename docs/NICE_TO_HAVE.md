# Nice-to-have backlog

These ideas are intentionally not implemented. They require product, operational,
privacy and often backend decisions beyond the static preview scope.

- Real online ordering
- Online payment
- Reservations
- Delivery service
- WhatsApp ordering
- Vietnamese as a third language
- Gift vouchers
- Complete allergen matrix
- Kitchen-ticket or printer integration
- Point-of-sale integration
- Loyalty program
- Automatic review synchronization
- PWA/offline menu
- QR table ordering

Do not add placeholder APIs, dependencies or empty UI for these items.
